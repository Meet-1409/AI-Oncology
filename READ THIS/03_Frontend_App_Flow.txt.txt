03_Frontend_App_Flow.txt

Project Name

AI Oncology Patient Intelligence Platform

Document Purpose

This document defines the complete frontend flow of the application. Every page, navigation path, button action, and user journey must follow this document. Developers must not change the navigation or workflow unless instructed by the Product Owner.

--------------------------------------------------

1. User Roles

There are only two user roles.

Patient

Oncologist

Every screen belongs to one of these roles.

6. Patient Workflow

Patient opens application.

↓

Login.

↓

Dashboard loads.

↓

Patient checks assigned tasks.

↓

If a task requires a report upload

↓

Patient uploads report.

↓

Upload completes.

↓

Patient receives confirmation.

↓

Timeline updates.

↓

Patient reads any notes from the oncologist.

↓

Logout.

19. Empty States

No notifications.

20. Error States

Failed login.

Incorrect credentials.

Failed upload.

Page not found.

--------------------------------------------------

22. Navigation Rules

Navigation must remain consistent across all pages.

The sidebar should remain identical throughout authenticated pages.

Users should always know where they are.

Users should never lose navigation context.

Every page should be reachable within a maximum of three interactions.

Back navigation should never lose unsaved work.

All workflows should remain simple and predictable.
