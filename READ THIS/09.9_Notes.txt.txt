09.9_Notes.txt

Project Name

AI Oncology Patient Intelligence Platform

Feature Name

Guidance (Notes)

Document Purpose

This document defines the Notes module. The module allows oncologists to write notes related to a patient's care. There are two types of notes: Shared Guidance (Patient Notes) and Private Observations (Private Clinical Notes). Every note remains linked to the Patient Case.

--------------------------------------------------

1. Purpose

Guidance allows oncologists to document important information throughout the patient's treatment journey.

Shared Guidance is written for the patient.

Private Observations are written only for the oncologist.

--------------------------------------------------

2. Target Users

Patient

Oncologist

--------------------------------------------------

3. Objectives

Allow oncologists to create notes.

Allow patients to read patient notes.

Allow oncologists to maintain private clinical notes.

Maintain complete note history.

Link every note to the patient's timeline.

--------------------------------------------------

4. Note Types

Shared Guidance (Patient Notes)

Visible to:

Patient

Oncologist

Purpose:

Provide instructions.

Explain follow-up steps.

Share important updates.

Use simple language.

--------------------------------------------------

Private Observations (Private Clinical Notes)

Visible to:

Oncologist only

Purpose:

Clinical observations.

Follow-up planning.

Personal reminders.

Treatment observations.

Private documentation.

--------------------------------------------------

5. Spatial Composition

For the patient, Shared Guidance appears in Patient Home Space alongside their Actions, in the patient's own language.

For the oncologist, Guidance is reached from the Contextual Orbit in Patient Space.

The two note types are always visually and spatially distinct so that a private observation can never be mistaken for something the patient can read. The distinction is explicit and never relies on color alone.

Writing a note happens in place, in Focus above the current space. The oncologist never leaves Patient Space to write.

The oncologist should enter:

Title

Message

Save

After saving:

The patient receives a notification.

The note becomes visible to the patient.

The note becomes part of the patient's timeline.

Before saving, it must be unmistakably clear that the note will be visible to the patient.

The oncologist should enter:

Title

Clinical Observation

Save

The note is stored.

The note becomes part of the patient's timeline.

The note remains visible only to the oncologist.

15. Notifications

Patients receive notifications when:

Oncologists do not receive notifications for their own notes.

--------------------------------------------------

16. Timeline Integration

Every note becomes part of the patient's timeline.

Patient Notes appear in:

Patient Timeline

Oncologist Timeline

Private Clinical Notes appear only in:

Oncologist Timeline

--------------------------------------------------

17. Motion

Writing a note lifts the composer into Focus above the current space.

Saving a note settles it into its position in Guidance and in the Journey, so the oncologist sees where it went.

New Shared Guidance is revealed to the patient with motion that draws attention without alarming them.

Reduced motion replaces these transitions with immediate cross-fades without any loss of information.

--------------------------------------------------

18. Business Rules

Only oncologists can create notes.

Patients cannot create notes.

Patients cannot edit notes.

Patients cannot delete notes.

Private Clinical Notes are never visible to patients.

Every note remains permanently linked to the Patient Case.

Every note keeps its creation history.

--------------------------------------------------

19. Empty States

No Patient Notes

Display informative message.

No Private Clinical Notes

Display informative message.

--------------------------------------------------

20. Error States

Failed to Save Note

Failed to Update Note

Network Error

Permission Denied

Display clear recovery instructions. A failed save must never lose the oncologist's written text.

--------------------------------------------------

21. Performance Requirements

Notes should load quickly.

Searching should remain responsive.

Filtering should update immediately.

Large note collections should support pagination.

--------------------------------------------------

22. Accessibility

Support keyboard navigation. Writing and saving have keyboard equivalents.

Maintain readable typography.

Provide descriptive labels for every action.

Maintain consistent spacing.

Note visibility must be communicated in text, never by color alone.

Respect reduced motion.

--------------------------------------------------

23. Completion Criteria

The Guidance module is complete when:

Oncologists can create Patient Notes.

Oncologists can create Private Clinical Notes.

Patients can view Patient Notes.

Patients cannot access Private Clinical Notes.

Searching functions correctly.

Filtering functions correctly.

Sorting functions correctly.

Timeline integration functions correctly.

Notifications function correctly.

The module is ready for backend integration.
