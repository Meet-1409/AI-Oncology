09.7_Patient_Intelligence.txt

Project Name

AI Oncology Patient Intelligence Platform

Feature Name

Understanding (Patient Intelligence)

Document Purpose

This document defines the Understanding module. It combines all validated patient information into a single clinical overview. It helps the oncologist understand the patient's condition without manually reviewing every report first.

--------------------------------------------------

1. Purpose

Understanding provides a complete overview of the patient's current clinical condition.

It summarizes the patient's journey using validated information while keeping every AI output linked to its original evidence.

The original reports always remain the source of truth.

Understanding is what the oncologist reads first. It exists so that no doctor has to search for the state of their patient.

--------------------------------------------------

2. Target User

Oncologist

--------------------------------------------------

3. Objectives

Provide a complete patient overview.

Display AI-generated clinical summary.

Display disease progression.

Display treatment progression.

Display supporting evidence.

Display confidence.

Provide quick access to related reports.

--------------------------------------------------

4. Spatial Composition

Understanding is reached from the Contextual Orbit in Patient Space and is also revealed in context when an organ on the Body or an event on the Journey is selected.

It is presented as a readable, continuous clinical narrative rather than a grid of metric boxes.

Information is revealed progressively. The summary appears first. Evidence and confidence are always attached to the statement they support, not collected in a separate area.

Every statement can be traced to its source without leaving Patient Space.

--------------------------------------------------

5. Presentation Order

Patient Information

Clinical Summary

Disease Overview

Treatment Overview

Disease Progression

Supporting Evidence

Confidence

Related Reports

--------------------------------------------------

6. Patient Information

Display:

Patient Name

Patient ID

Age

Gender

Primary Diagnosis

Current Stage

Current Treatment

Treating Oncologist

--------------------------------------------------

7. Clinical Summary

Display a structured overview generated from validated patient information.

The summary should focus on:

Current Condition

Important Clinical Findings

Recent Changes

Current Treatment Status

Recent Investigations

--------------------------------------------------

8. Disease Overview

Display:

Primary Cancer

Primary Site

Affected Organs

Current Disease Status

Disease Progression

Disease Severity

Selecting an affected organ moves attention to that organ on the Body.

--------------------------------------------------

9. Treatment Overview

Display:

Current Treatment

Previous Treatments

Recent Treatment Changes

Treatment Timeline

--------------------------------------------------

10. Disease Progression

Display how the patient's condition has changed over time.

Include:

Recent Improvements

Recent Progression

Stable Findings

Recent Clinical Events

Progression, regression and stability must be distinguishable without relying on color alone.

--------------------------------------------------

11. Report Summary

Display a summary of important uploaded reports.

Each report should display:

Report Name

Report Type

Report Date

Summary

View Report

--------------------------------------------------

12. Supporting Evidence

Every AI-generated result must provide supporting evidence.

Display:

Evidence Source

Report Name

Report Date

Relevant Findings

Open Report

Evidence is presented alongside the statement it supports. Opening a report enters Focus without leaving Patient Space.

--------------------------------------------------

13. Confidence

Every AI-generated result should display its confidence.

Confidence should be shown for:

Clinical Summary

Disease Progression

Report Comparison

Disease Visualization

Confidence is always visible and is never hidden behind an additional interaction.

--------------------------------------------------

14. Timeline Integration

Every section links back to the patient's Journey.

Users should be able to open the related timeline event directly.

--------------------------------------------------

15. Digital Twin Integration

Understanding connects directly to the Body.

Users should be able to:

Open the Digital Twin.

View the related disease visualization.

Compare previous and current disease states.

Selecting a finding moves attention to the corresponding site on the Body.

--------------------------------------------------

16. Search

Allow searching within Understanding.

Search should include:

Clinical Findings

Reports

Treatments

Timeline Events

--------------------------------------------------

17. Filters

Support filtering by:

Date

Treatment

Report Type

Disease Status

--------------------------------------------------

18. Motion

Understanding is revealed alongside the Body without displacing it.

Selecting a finding moves attention to the related site on the Body with continuous motion.

Newly generated intelligence is revealed with motion that draws attention to what changed.

Reduced motion replaces these transitions with immediate cross-fades without any loss of information.

--------------------------------------------------

19. User Actions

View Clinical Summary

Open Timeline

Open Report

Open Digital Twin

Search Information

Filter Information

--------------------------------------------------

20. Business Rules

Every Patient Intelligence result must be generated from validated patient information.

Every AI output must be linked to supporting evidence.

Every AI output must display confidence.

The original report must always remain accessible.

Patient Intelligence must never replace the original reports.

--------------------------------------------------

21. Empty States

No Patient Intelligence Available

Display informative message.

No Supporting Evidence Available

Display informative message.

No Reports Available

Display informative message.

--------------------------------------------------

22. Error States

Unable to Generate Summary

Missing Patient Data

Network Error

AI Processing Error

Display clear recovery instructions. An AI failure must never break the surrounding space.

--------------------------------------------------

23. Performance Requirements

Understanding should load quickly.

Large patient histories should remain responsive.

Search and filtering should update efficiently.

Opening related reports should not interrupt the current workflow.

--------------------------------------------------

24. Accessibility

Support keyboard navigation. Every spatial action has a keyboard equivalent.

Maintain readable typography.

Provide descriptive labels for every interactive element.

Maintain consistent spacing.

Progression and confidence must never rely on color alone.

Respect reduced motion.

--------------------------------------------------

25. Completion Criteria

Understanding is complete when:

Clinical Summary is displayed.

Disease Overview is displayed.

Treatment Overview is displayed.

Disease Progression is displayed.

Supporting Evidence is displayed.

Confidence is displayed.

Timeline integration functions correctly.

Digital Twin integration functions correctly.

The module is ready for backend integration.
